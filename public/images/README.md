# Images Directory Guide for Mukesh Portfolio

Aap apni photos aur images ko yaha is folder me rakh sakte hain. Sabhi images automatically website par show hone lagenge!

## 📸 File Names and Where They Appear:

1. **`hero-avatar.jpg` (or `.png`)**
   - **Kaha dikhega**: Top Hero section me (Main profile picture).
   - **Recommended size**: 600x800 px (Portrait, Clean background).

2. **`about-avatar.jpg` (or `.png`)**
   - **Kaha dikhega**: "About Me" section me.
   - **Recommended size**: 600x800 px (Square ya Portrait).

3. **`projects/` folder**:
   - `project-1.jpg`: Project 1 (e.g., Indian Cuisine App mockup)
   - `project-2.jpg`: Project 2 (e.g., E-Commerce store screenshot)
   - `project-3.jpg`: Project 3 (e.g., Agency website screenshot)
   - `project-4.jpg`: Project 4 (e.g., Dashboard screenshot)
   - **Recommended size**: 800x600 px ya 1200x900 px.

4. **`Mukesh_Resume.pdf`**:
   - Aap apna real resume yaha `Mukesh_Resume.pdf` naam se rakh dijiye, taaki "Download CV" button par click karne se aapka CV download ho jaye.

---

Agar aap file ka naam change karna chahte hain ya naya project add karna chahte hain, toh simply open karein:
`src/data/portfolioData.js`
Aur waha image path change kar dijiye!
